# BISMILLAH BARAKA — Telegram Mini App магазин

Готовый магазин внутри Telegram для бизнеса в Мекке: **🍽 Меню**, **🤲 Садака**, **🏞 Мероприятия**, корзина, заказы, склад (остатки), оплата **💵 наличными** или **🏦 банковским переводом с фото чека**, админ-панель с телефона, статистика, уведомления в группу. Два языка: **O‘zbekcha** (основной) и **Русский**.

Никаких платёжных систем (Stripe, PayPal, банковских API) нет — только наличные и перевод по реквизитам.

## Что внутри

**Для клиента (Mini App):**
- Главный экран: логотип → название → три больших карточки 🍽 МЕНЮ, 🤲 САДАКА, 🏞 МЕРОПРИЯТИЯ (разделы не смешиваются).
- Меню по категориям: ⭐ Наш сет, 🍳 Завтрак, 🍲 Первые блюда, 🍛 Вторые блюда, 🥗 Салаты, 🥤 Напитки.
- У каждого товара есть своя страница: фото, название, описание, цена в SAR, остаток.
- Остаток: «Осталось: 12 шт.», при малом остатке «🔥 Осталось только 3 шт.», при нуле «❌ Нет в наличии» (кнопка недоступна).
- Корзина: изменить количество, удалить, суммы по строкам и итог, «🛒 Оформить заказ».
- Оформление: имя, телефон, 📍 адрес/место доставки в Мекке, комментарий, самовывоз (если включён админом).
- Оплата: 💵 наличными или 🏦 переводом — показываются реквизиты, клиент отправляет фото чека.
- Профиль: имя, телефон, язык, история заказов «Заказ №1024 / 23.09.2026 / 70 SAR / Статус», подробности и «🔄 Повторить заказ».
- Нижнее меню: 🏠 Главная, 🍽 Меню, 🤲 Садака, 🛒 Корзина, 👤 Профиль.
- Клиент регистрируется **автоматически** через Telegram — ничего вводить не нужно.
- Каждый клиент видит **только свои** заказы.

**Для администратора (админ-панель внутри Telegram):**
- 📊 Статистика: заказы и выручка за сегодня / 7 дней / месяц, продано товаров, топ товаров, остатки, заказы по статусам.
- 🧾 Заказы: все детали, ник Telegram, телефон (звонок/WhatsApp), товары, чек, подтверждение/отклонение оплаты, смена статуса, заметка.
- 📦 Товары: добавить, изменить, удалить, скрыть/показать, цена, остаток (кнопки − / + прямо в списке), фото, описание на двух языках, категория, раздел, мин./макс. количество.
- 🗂 Категории: добавить / переименовать / скрыть / удалить.
- 👥 Клиенты: все клиенты, их телефоны, количество заказов, сумма покупок, история заказов каждого (для анализа рынка).
- ⚙️ Настройки: название, логотип, описание, телефон, WhatsApp, Instagram, адрес, рабочее время (открыто/закрыто, часы, принимать ли заказы вне времени), доставка/самовывоз, реквизиты банка, приветствие, основной язык, валюта.

**Статусы заказа:** 🆕 Новый · 💳 Ожидает оплаты · 🔎 Проверка оплаты · ✅ Оплачен · 👨‍🍳 Готовится · 📦 Готов · 🚚 Доставляется · ✅ Выполнен · ❌ Отменён.

## Как это устроено (коротко)

- **Одна команда запускает всё**: `python run.py` запускает и сайт (Mini App + админку + API), и Telegram-бота. Отдельно бота запускать не нужно.
- **Сайт**: FastAPI (Python). **Бот**: aiogram 3. **База**: SQLite — один файл `database/shop.db`, ничего устанавливать не нужно.
- **Frontend**: обычные HTML/CSS/JS, без сборки.
- **Админ-панель** — это страница `https://ваш-домен/admin`, она открывается кнопкой «👨‍💼 Админ-панель» в боте. Эта кнопка видна только администраторам, а сервер проверяет права при каждом действии.
- **Отдельная база данных для каждого клиента не нужна**: все заказы в одной базе, но сервер строго отдаёт клиенту только его заказы. Администраторы видят всех клиентов во вкладке «👥 Клиенты».
- **Цена и остаток всегда проверяются на сервере.** Клиент не может изменить цену. Остаток уменьшается атомарно: если два клиента одновременно заказывают последнюю штуку, получит только один, второй увидит сообщение «Извините, осталось только N шт.» или «Нет в наличии». Остаток никогда не уходит в минус. При отмене заказа товар возвращается на склад.

## Шаг 1. Установить Python

Нужен Python **3.11 или новее** (рекомендуется 3.12).

**Windows**
1. Откройте https://www.python.org/downloads/ и скачайте последнюю версию.
2. При установке **обязательно поставьте галочку «Add Python to PATH»**.
3. Откройте «Командную строку» (Win + R → `cmd`) и проверьте: `python --version`.

**macOS**: скачайте установщик с https://www.python.org/downloads/ и проверьте в «Терминале»: `python3 --version`.

**Ubuntu / Debian сервер**:
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip
python3 --version
```

> На macOS/Linux вместо `python` пишите `python3`, вместо `pip` — `pip3`.

## Шаг 2. Создать бота в BotFather

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Start».
2. Отправьте `/newbot`.
3. Введите название, например `BISMILLAH BARAKA`.
4. Введите username бота — должен заканчиваться на `bot`, например `bismillah_baraka_bot`.
5. BotFather пришлёт **токен** — строку вида `1234567890:AAH...`.

Настраивать `/setdomain` и `/newapp` **не нужно**: кнопка «🛍 Открыть магазин» и кнопка меню бота настраиваются программой автоматически.

## Шаг 3. Получить и вставить BOT_TOKEN

1. Распакуйте архив в папку, например `C:\bismillah-baraka` или `/opt/bismillah-baraka`.
2. Сделайте копию файла `.env.example` и назовите её **`.env`** (с точкой в начале).
   - Windows: `copy .env.example .env`
   - macOS/Linux: `cp .env.example .env`
3. Откройте `.env` в Блокноте и вставьте токен:
   ```
   BOT_TOKEN=1234567890:AAH....ваш_токен
   ```

> ⚠️ Токен — это пароль от бота. Никому его не отправляйте и не вставляйте в код. Если токен кто-то увидел — в @BotFather: `/mybots` → ваш бот → **API Token** → **Revoke current token**, и вставьте новый в `.env`.

## Шаг 4. Узнать свой Telegram ID

Telegram ID — это число (не @username).
1. Напишите боту **@userinfobot** любое сообщение.
2. Он ответит `Id: 8427839550` — это ваш ID.

## Шаг 5. Указать ADMIN_IDS

В `.env`:
```
ADMIN_IDS=8427839550
```
Несколько администраторов — через запятую: `ADMIN_IDS=8427839550,123456789`.
После изменения `.env` перезапустите программу.

Только эти люди видят кнопку «👨‍💼 Админ-панель» и могут управлять магазином. Остальные получат «⛔ Доступ только для администраторов».

## Шаг 6. Запустить проект на компьютере

В папке проекта выполните:

**Windows**
```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

**macOS / Linux**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Появится `Uvicorn running on http://0.0.0.0:8000` — сайт работает. База данных и стандартные категории создаются автоматически при первом запуске.

Хотите сразу увидеть магазин с примерами блюд? Выполните один раз (в другом окне, в той же папке с активированным venv):
```bash
python scripts/seed_demo.py
```
Примеры потом можно удалить или изменить в админке.

**Посмотреть в обычном браузере (без Telegram)** — только для проверки на своём компьютере:
в `.env` поставьте `DEV_MODE=true` и `DEV_USER_ID=ваш_ID`, перезапустите и откройте http://localhost:8000 и http://localhost:8000/admin.
**На реальном сервере `DEV_MODE` должен быть `false`!**

Проверка, что всё работает (необязательно):
```bash
pip install httpx
python tests/test_api.py
```
Тест запускает отдельную временную базу и проверяет заказы, остатки, права админа, чеки и одновременные заказы. Ваша база не затрагивается.

## Шаг 7. Открыть Mini App в Telegram

Telegram открывает Mini App **только по адресу https://**. `http://localhost` в Telegram не откроется.

Для проверки на своём компьютере сделайте временный HTTPS-адрес:

**Вариант А — Cloudflare Tunnel (бесплатно, без регистрации):**
1. Скачайте `cloudflared`: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. Пока работает `python run.py`, в другом окне выполните:
   ```bash
   cloudflared tunnel --url http://localhost:8000
   ```
3. Появится адрес вида `https://something-random.trycloudflare.com`.

**Вариант Б — ngrok:** зарегистрируйтесь на https://ngrok.com, затем `ngrok http 8000`.

Дальше:
1. Вставьте адрес в `.env`: `WEBAPP_URL=https://something-random.trycloudflare.com` (без `/` в конце).
2. Перезапустите `python run.py` (Ctrl + C, затем снова).
3. Откройте своего бота в Telegram → `/start` → **«🛍 Открыть магазин»**.
4. Администратор увидит ещё кнопку **«👨‍💼 Админ-панель»** (или команда `/admin`).

> Временный адрес меняется при каждом запуске туннеля — для постоянной работы нужен сервер (шаг 8).

## Шаг 8. Разместить на сервере

Нужен VPS-сервер (Ubuntu 22.04/24.04, 1 ГБ RAM достаточно) и домен (например `shop.bismillahbaraka.com`). Подойдёт любой хостинг: Hetzner, DigitalOcean, Contabo, Timeweb и т.п.

1. У регистратора домена создайте **A-запись**: `shop` → IP вашего сервера.
2. Подключитесь к серверу (`ssh root@IP`) и загрузите папку проекта, например в `/opt/bismillah-baraka` (через `scp`, WinSCP или FileZilla).

### Способ 1 (рекомендуется, самый простой): Docker — HTTPS настроится сам

```bash
# установить Docker
curl -fsSL https://get.docker.com | sh

cd /opt/bismillah-baraka
cp .env.example .env
nano .env          # впишите BOT_TOKEN, ADMIN_IDS, WEBAPP_URL, SECRET_KEY
nano deploy/Caddyfile   # замените shop.example.com на ваш домен
docker compose up -d --build
```
Готово: Caddy сам получит бесплатный HTTPS-сертификат.
- Логи: `docker compose logs -f app`
- Перезапуск после изменения `.env`: `docker compose up -d --force-recreate app`
- Обновление кода: загрузите новые файлы и `docker compose up -d --build`

База (`database/`), фото и чеки (`uploads/`) хранятся в папках на сервере и не пропадают при перезапуске.

### Способ 2: без Docker (systemd + nginx)

```bash
sudo apt install -y python3-venv nginx certbot python3-certbot-nginx
cd /opt/bismillah-baraka
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
sudo chown -R www-data:www-data /opt/bismillah-baraka
sudo cp deploy/bismillah-baraka.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now bismillah-baraka
sudo systemctl status bismillah-baraka
```
Затем настройте nginx по инструкции в `deploy/nginx.conf` (шаг 9).

## Шаг 9. Подключить HTTPS

- **Docker (способ 1)** — ничего делать не нужно, Caddy делает HTTPS автоматически. Главное: домен уже указывает на IP сервера и открыты порты 80 и 443.
- **nginx (способ 2)**:
  ```bash
  sudo cp deploy/nginx.conf /etc/nginx/sites-available/shop
  sudo nano /etc/nginx/sites-available/shop      # замените shop.example.com на свой домен
  sudo ln -s /etc/nginx/sites-available/shop /etc/nginx/sites-enabled/shop
  sudo nginx -t && sudo systemctl reload nginx
  sudo certbot --nginx -d shop.ваш-домен.com
  ```
  Сертификат продлевается автоматически.

Проверка: откройте в браузере `https://ваш-домен/api/health` — должно быть `{"ok":true}`.

## Шаг 10. Указать WEBAPP_URL

В `.env`:
```
WEBAPP_URL=https://shop.ваш-домен.com
```
- обязательно `https://`
- без `/` в конце
- после изменения — перезапуск (`docker compose up -d --force-recreate app` или `sudo systemctl restart bismillah-baraka`).

При запуске бот сам установит кнопку меню «🛍 Do'kon» слева от поля ввода.

## Шаг 11. Поменять логотип и название

Админ-панель → **⚙️ Настройки** → блок «🏪 Бизнес»:
- «Загрузить логотип» — выберите картинку (лучше квадратную, PNG/JPG). Пока логотип не загружен, показывается стандартный значок.
- «Название бизнеса» — например `BISMILLAH BARAKA`.
- Описание на узбекском и русском.
- Нажмите **💾 Сохранить настройки**.

Там же: телефон, WhatsApp, Instagram, адрес, рабочее время, текст приветствия бота, реквизиты банка.

**Рабочее время:** переключатель «Магазин открыт», время открытия и закрытия (время Мекки). Когда магазин закрыт, клиенты видят «Сейчас мы закрыты», но меню можно смотреть. Галочка «Принимать заказы вне рабочего времени» разрешает или запрещает заказы в это время. Если время открытия и закрытия одинаковое — магазин работает круглосуточно.

## Шаг 12. Добавить первый товар

1. Админ-панель → **📦 Товары**.
2. Сверху выберите раздел: 🍽 Меню, 🤲 Садака или 🏞 Мероприятия.
3. Нажмите **➕ Добавить товар**.
4. Заполните:
   - Фото (необязательно — без фото будет красивая заглушка);
   - Раздел и категория (например «⭐ Наш сет» или «🍛 Вторые блюда»);
   - Название и описание на **UZ** и **RU** (если один язык не заполнен — покажется другой);
   - Цена в SAR (например `25` или `12.50`);
   - Остаток — сколько штук в наличии;
   - Мин./макс. количество в одном заказе (необязательно);
   - «Показывать клиентам» — включено.
5. **💾 Сохранить.** Товар сразу появится в магазине.

«⭐ Наш сет» — отдельная категория: у сета своё фото, цена, описание и остаток, добавляется так же, как обычный товар.

Категории можно менять кнопкой **🗂 Категории** (иконка, название на двух языках, порядок, скрыть).

## Шаг 13. Изменить цену

📦 Товары → нажмите на товар → поле «Цена, SAR» → **💾 Сохранить**.
Новая цена действует сразу для новых заказов. В уже оформленных заказах сохраняется цена на момент заказа.

## Шаг 14. Изменить остаток

- Быстро: в списке товаров кнопки **−** и **+** (по 1 шт.).
- Точно: нажмите на число «12 шт.» и введите новое количество.
- Или в карточке товара — поле «В наличии».

Остаток автоматически уменьшается при каждом заказе и возвращается при отмене. Все изменения записываются в журнал склада. Кнопка 👁/🚫 — скрыть/показать товар.

## Шаг 15. Посмотреть заказ

Новый заказ приходит:
- в группу уведомлений и в личку администраторам (номер, ник Telegram, телефон, товары, сумма, способ оплаты, адрес), с кнопками статусов и **[Открыть заказ]**;
- в админ-панель → **🧾 Заказы** (фильтры: активные, все, по статусу; поиск по номеру, имени, телефону).

В заказе: клиент, ссылка на его Telegram, телефон (позвонить или WhatsApp), адрес, комментарий, товары, сумма, оплата, чек. Меняйте статус кнопками: 👨‍🍳 Готовится → 📦 Готов → 🚚 Доставляется → ✅ Выполнен. Клиент автоматически получает сообщение в боте о смене статуса.

«❌ Отменить заказ» — с подтверждением; товары возвращаются на склад. Отменённый заказ восстановить нельзя (чтобы остаток не посчитался дважды).

## Шаг 16. Подтвердить банковский перевод

1. Клиент выбирает «🏦 Банковский перевод», видит ваши реквизиты и отправляет фото чека. Статус заказа — «🔎 Проверка оплаты».
2. Вам приходит сообщение «📎 Чек прикреплён» с фото чека и кнопками **✅ Подтвердить оплату** / **❌ Отклонить оплату**.
3. Проверьте поступление денег в банковском приложении.
4. Нажмите кнопку в Telegram или в админке (🧾 Заказы → заказ → «✅ Подтвердить» / «❌ Отклонить»).
   - Подтвердили → статус «✅ Оплачен», клиенту приходит уведомление.
   - Отклонили (можно указать причину) → статус «💳 Ожидает оплаты», клиент может отправить чек заново.

Реквизиты (банк, получатель, IBAN, счёт, дополнительный текст) меняются в ⚙️ Настройки → «🏦 Реквизиты банковского перевода».

## Шаг 17. Где хранятся чеки

- Файлы чеков: папка **`uploads/receipts/`** на сервере.
- Фото товаров: `uploads/products/`, логотип: `uploads/logo/`.
- Чеки **не доступны посторонним**: в админке они открываются по временной подписанной ссылке (действует 1 час). Просто угадать адрес чека нельзя.
- Посмотреть чек: админка → 🧾 Заказы → заказ → блок «💳 Оплата» (нажмите на фото, чтобы открыть крупно). Также чек приходит фото в Telegram.

## Шаг 18. Резервная копия базы данных

Все данные: файл **`database/shop.db`** + папка **`uploads/`**.

Сделать копию (можно во время работы магазина):
```bash
python scripts/backup.py
# Docker:
docker compose exec app python scripts/backup.py
```
Копии появятся в папке `backups/` (`shop-ДАТА.db` и `uploads-ДАТА.zip`), хранятся последние 30.

**Автоматически каждую ночь** (Linux, `crontab -e`):
```
0 3 * * * cd /opt/bismillah-baraka && docker compose exec -T app python scripts/backup.py
```
(без Docker: `0 3 * * * cd /opt/bismillah-baraka && venv/bin/python scripts/backup.py`)

Периодически скачивайте папку `backups/` к себе на компьютер или в облако.

**Восстановление:** остановите программу, замените `database/shop.db` файлом из копии (переименуйте `shop-ДАТА.db` → `shop.db`), распакуйте `uploads-ДАТА.zip` в папку проекта, запустите снова.

## Уведомления в группу

В `.env`: `NOTIFY_CHAT_ID=@botbismillahbarakosh` (для группы https://t.me/botbismillahbarakosh).

1. **Добавьте бота в группу** (Настройки группы → Участники → Добавить → ваш бот).
2. Лучше сделайте бота администратором группы (право отправлять сообщения).
3. Если группа **закрытая** (без @username), `@username` не сработает: напишите в группе команду `/chatid` (от имени администратора из ADMIN_IDS) — бот ответит числом вида `-1001234567890`. Вставьте его: `NOTIFY_CHAT_ID=-1001234567890` и перезапустите.

Сообщение о заказе содержит: номер заказа, имя, ник Telegram, телефон, названия и количество товаров, сумму, способ оплаты, адрес, статус, «📎 Чек прикреплён» (для перевода), кнопки статусов и **[Открыть заказ]**.

> Почему кнопка «Открыть заказ» — ссылка на бота: Telegram не разрешает кнопки Mini App в группах. Ссылка открывает личный чат с ботом, и бот показывает заказ с кнопкой «Открыть в админ-панели». Кнопки статусов в группе работают только у администраторов из ADMIN_IDS.

`NOTIFY_ADMINS_PRIVATE=true` — дополнительно дублировать уведомления администраторам в личку (администратор должен хотя бы раз нажать /start в боте).

## Безопасность

- Каждый запрос Mini App подписан Telegram (`initData`); сервер проверяет подпись с помощью BOT_TOKEN. Подделать пользователя нельзя.
- Цены, суммы и остатки считаются только на сервере.
- Админские функции — только для Telegram ID из `ADMIN_IDS`, проверка на сервере при каждом запросе.
- Секреты только в `.env` (не в коде). Файл `.env` не отправляйте никому и не публикуйте.
- `DEV_MODE=true` — только для проверки на своём компьютере. На сервере — `false`.
- Загружаемые картинки проверяются и пересохраняются (размер ограничен `MAX_UPLOAD_MB`).

## Частые проблемы

| Проблема | Решение |
|---|---|
| Бот не отвечает | Проверьте `BOT_TOKEN` в `.env`. В логах будет «❌ Неверный BOT_TOKEN». Запущен ли `python run.py`? |
| Нет кнопки «Открыть магазин» | `WEBAPP_URL` должен начинаться с `https://`. Перезапустите программу. |
| Mini App пишет «Откройте через Telegram» | Открывайте кнопкой в боте, а не ссылкой в браузере. |
| Нет кнопки админ-панели | Ваш ID должен быть в `ADMIN_IDS`; после изменения — перезапуск и снова `/start`. |
| Уведомления не приходят в группу | Бот добавлен в группу? Для закрытой группы нужен числовой ID (команда `/chatid`). |
| Не приходят уведомления в личку | Администратор должен один раз нажать `/start` в боте. |
| «Сейчас мы закрыты» | ⚙️ Настройки → Рабочее время: проверьте переключатель и часы (время Мекки). |
| Порт 8000 занят | В `.env` поменяйте `PORT=8001`. |

## Переход на PostgreSQL

SQLite отлично подходит для одного магазина. Если понадобится PostgreSQL:
1. `pip install asyncpg` (или раскомментируйте строку в `requirements.txt`).
2. В `.env`: `DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/shop`
3. Запустите — таблицы создадутся автоматически. (Данные из SQLite переносятся отдельно, например через `pgloader`.)
